# Integration Test Instructions

1. Start with `npm run dev`.
2. Open the New Project dialog.
3. Verify Personal and Work prefill their respective homeserver and Mac bases.
4. Edit both base fields and enter a project name.
5. Submit and verify the derived folder is created.
6. Return to Projects and verify the new project is listed.
7. With sync enabled, verify the generated AGENTS.md contains the derived Mac path.
