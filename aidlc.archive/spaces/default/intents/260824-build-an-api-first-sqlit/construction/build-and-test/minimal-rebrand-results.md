## UI Unification Pass (final)

- **One header component.** All three columns use a fixed 64px header with the same title size (19px serif), the same mono subtitle, and the same action alignment, so titles share a baseline. The `#projectsPanel .panel-bar { flex-wrap: wrap }` rule — the actual cause of the taller first column — was removed, and header text now truncates rather than wrapping.
- **Shared overflow pattern.** Theme, GitHub and Nodes moved into a `.panel-toolbar` revealed by a `⋯` button, the same mechanism the chat header already used. `+ Project` became an icon button so the header holds one row at any column width.
- **Per-column hue.** `--hue` is set per panel (`#projectsPanel` teal, `#chatsPanel` blue, `#boardPanel` amber, `#chatPanel` violet) and drives the header wash, the 2px top rule, the panel body tint, the section-label rule, the selection bar, and the matching bottom-nav icon.
- **Row actions.** The fixed 140px gutter was replaced with a hover/active gradient (`.list-row::after`), so project and conversation names use the full row width; the gradient only appears when the buttons do.
- **Selection states redone.** Filter chips are outlined pills, the engine toggle tints its label, and selected rows are a raised surface with a hue edge instead of a tinted blob.
- **Form language.** `<select>` gained an inline-SVG caret. Fixed a real bug found during verification: `.dialog-card :is(input, textarea, select) { background: … }` used the shorthand, which reset `background-image` and erased the caret; all four such rules now use `background-color`.
- **Cleanups.** Removed dead duplicate declarations (`.list-row.active .row-action-button`, `.eyebrow`) and the stale wrap rule.
