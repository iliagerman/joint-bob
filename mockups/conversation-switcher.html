Switch between recent conversations

Hold the chord, tap the cycle key to step through your last 10 conversations, and release to open the one selected. A quick tap toggles between the last two, the way Cmd+Tab does. This page is a mock: it runs on fake data, so you can try the keys here before anything is built.

Decisions to confirm

  1. Mac chord: Control+Option held, Tab cycles forward, Shift+Tab goes back. It matches the command shortcuts already in the app, and Tab is not used by any of them.
  2. Windows chord: Ctrl+Shift held, Space cycles (proposed). Ctrl+Tab and Ctrl+Shift+Tab are browser tab keys and cannot be captured. Ctrl+Alt is AltGr on many Windows keyboard layouts, so it would type characters. Pick a different key if you prefer.
  3. Order: most recently used first. The current conversation is always row 1, and a conversation counts once even if you visit it several times.
  4. Digits 1–0 (my addition): while the switcher is open, a digit jumps straight to that row and opens it.
  5. Release commits: letting go of the chord opens the selected row. Escape cancels. Clicking a row also opens it.
